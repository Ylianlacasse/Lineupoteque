Chaque modification est enregistrée automatiquement dans le fichier lineups.json de ton dépôt. Le token reste uniquement dans ce navigateur : à saisir une fois sur chaque appareil.

Créer le token : GitHub › Settings › Developer settings › Personal access tokens › Fine-grained tokens. Accès limité au dépôt Lineupoteque, permission « Contents : Read and write ».
